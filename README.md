# CSV Cleaner Tool (Beginner Data Engineering Project)

A simple and effective CSV cleaning tool written in pure Python (no Pandas, no NumPy).  
You can use this to remove duplicates, clean columns, remove empty rows, and export a fresh CSV.

---

## Features
✔ Remove duplicate rows  
✔ Remove fully empty rows  
✔ Clean column names  
✔ Strip whitespace  
✔ Save cleaned CSV  

---

## Usage

1. Place your raw CSV in the `data/` folder.
2. Run the script:
python main.py data/raw.csv
3. Cleaned file will appear at:
data/cleaned_output.csv
